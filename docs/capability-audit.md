# 核心能力契约审计

本项目维护一组可重复执行的最低能力契约，用于防止重构时意外删除关键路由、MCP 工具、指标和规范字段。

当前审计范围：

- 23 个关键业务路由必须存在。
- 5 个 MCP 只读工具必须存在。
- 12 个基础 Prometheus 指标必须存在。
- 支付、用户与交易模型必须使用单一规范字段，不保留同义双写字段。
- Node Exporter 等必要运行资产必须存在。

当前实现已在最低契约之上增加管理、复核、可观测性、缓存、预计算、向量检索、自动重试和告警能力。

执行以下命令可重复验证：

```bash
pnpm audit:capabilities
```
