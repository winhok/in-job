# 产品能力完整闭环

## 问题

当前仓库已经完成简历智能押题、模拟面试、异步评估报告和微信服务号扫码登录，但前端仍调用多个不存在的后端接口，支付与 STS 模块仍为空实现，充值与兑换界面保留 TODO，历史记录和简历管理无法形成完整闭环。长对话压缩、结构化日志、请求追踪、指标监控和生产部署等运行能力也尚未完整落地。

## 能力现状

- 核心用户、JWT、AI、押题、模拟面试、报告和微信登录主体已经实现。
- 最近消息截断已实现；长对话总结和定时清理尚未接入实际调用链。
- 前端已经声明但服务端缺少的契约包括简历 CRUD、三类历史记录、未完成面试、问答结果、会话历史、管理员面试人数和 STS 临时凭证。
- 订单、支付宝、微信支付、主动查询、幂等发货、充值流水和旺旺币兑换尚未实现。
- Winston、TraceID、日志脱敏、Prometheus 指标、告警与部署资产尚未完整实现。
- 多模型、流式输出和评估已有实现；RAG 尚无产品化入口。

## 范围

- 以产品最低能力契约为基线，保留关键模块、接口、Schema、MCP 和监控能力，并在单一规范字段模型上实现扩展。
- 补齐前端已使用的后端 API，并统一前后端方法、参数、所有权和分页契约。
- 增加用户简历持久化与受所有权保护的增删改查，补齐 OSS STS 的安全服务端配置边界。
- 补齐面试历史、详情、未完成列表、恢复会话和管理员实时统计。
- 实现支付宝与微信支付的订单状态机、签名或 SDK 适配、主动查询、回调、金额校验、并发幂等发货、充值流水和用户查询。
- 实现旺旺币兑换、一次性分享奖励和前端充值/兑换/记录闭环。
- 将长对话总结与过期会话清理接入实际运行路径，并增加面向面试知识的可插拔 RAG 检索边界。
- 落地结构化日志、请求 TraceID、敏感字段脱敏、AI/HTTP/业务指标和 Prometheus/Grafana 配置。
- 增加安全的示例环境变量、生产构建、容器、PM2、Nginx 和健康检查资产。
- 为新增状态机、权限、并发和失败路径增加自动化测试。

## 非目标

- 不增加无业务用途的框架演示模块。
- 不提交真实密钥、商户证书、内部地址、生产域名或本机绝对路径。
- 不调用真实支付、微信菜单、OSS、模型、告警通知或生产部署接口。
- 不把本地 mock、单元测试、构建或配置文件存在误报为真实第三方联调、正式验收或生产发布。
- 不扩展医疗、客服、教育或创意写作等无关独立产品。

## 受影响契约

- 新增 `/resume/*`、`/sts/getStsToken`、`/admin/interview-count` 和缺失的 `/interview/*` 查询接口。
- 新增 `/payment/order`、`/payment/order/status`、支付回调与用户交易记录接口。
- 新增 `/interview/exchange-package` 和一次性分享奖励接口；所有余额与次数变更必须使用条件原子更新并留存流水。
- 支付金额与套餐权益由服务端目录决定，客户端金额、套餐名、用户和成功状态均不可信。
- 第三方凭据缺失时接口返回明确的配置不可用错误，不提供伪造成功结果。
- `/metrics` 与健康检查不泄露凭据、用户输入、简历原文或内部异常堆栈。

## 风险

- 支付与权益发放涉及资金和并发一致性，必须覆盖金额校验、订单所有权、重复回调、处理中恢复和部分失败补偿。
- STS 和简历 URL 涉及文件访问权限，必须限制文件键前缀、凭证有效期和用户所有权，不能信任客户端传入任意对象地址。
- 现有模拟面试会话部分存于进程内存；多实例与进程重启恢复需要以数据库快照为准。
- RAG 和长对话总结会增加模型调用成本；配置缺失或调用失败时必须安全降级，不阻断主面试流程。
- 监控标签如果包含用户或任意路径会造成敏感信息泄露和高基数，标签集合必须受控。
- 测试金额、硬编码套餐和简化错误处理不能进入生产产品。

## 验收标准

- 前端业务 API 清单与 Nest 控制器清单不存在未登记的缺口，关键请求/响应契约有自动化测试。
- 用户只能查看和修改自己的简历、面试结果、订单和流水；管理员统计有明确的管理员保护或仅返回非敏感聚合值。
- 支付订单可在模拟 provider 下完成创建、查询、回调、幂等发货和流水记录；重复或越权请求不会重复增加余额或次数。
- 旺旺币兑换在余额充足时原子扣减并增加一次权益，余额不足和并发竞争不会透支。
- 长对话受消息数量约束，摘要失败可降级；过期会话能被定时清理；RAG 未配置时主流程仍可运行。
- 日志默认脱敏并带 TraceID，指标端点能输出受控的 HTTP、AI 和业务指标。
- 服务端测试、前端构建、服务端构建、契约审计和 `deliveryguard check` 通过，或对环境限制给出具体证据。
