# 产品能力完整闭环技术设计

## 分片顺序

实现按依赖分为四个可独立验证的纵向切片：

1. **基础业务闭环**：简历、历史、详情、续面、管理员统计、前端契约修正。
2. **资金与权益闭环**：订单、provider、查询/回调、幂等发货、流水、兑换和充值界面。
3. **AI 扩展与运行质量**：长对话摘要/清理、RAG 边界、TraceID、脱敏日志、指标。
4. **交付资产**：示例配置、健康检查、容器、PM2、Nginx、Prometheus/Grafana 与验证脚本。

每个切片先补测试再完成代码，并在任务清单中只勾选真实完成项。

## API 契约收敛

以前端 `app/api` 为消费方清单、Nest controller 为提供方清单，建立自动化契约测试。已有安全且语义清晰的服务端接口优先保留，前端错误路径（例如用户更新方法不一致）改为调用真实契约，不增加无意义兼容别名。

所有列表接口统一返回 `{ records, total, page, limit }`。所有资源查询同时绑定 JWT 用户 ID；数据库 ObjectId 在 DTO 边界转换为字符串 `resultId` 或 `resumeId`。

模拟面试的数据库结果是重建内存会话的事实源。恢复时只从所属用户的未结束结果重建必要上下文，不信任客户端提交的历史或用户标识。

## 支付状态机与 provider 边界

支付 provider 统一实现“创建订单、主动查询、验证回调”三个能力。真实支付宝和微信实现只读取服务端配置；测试使用确定性 fake provider，不通过生产开关伪造支付成功。

```text
pending --provider paid + atomic claim--> processing --grant + ledger--> success
   |                                        |
   +--expired/closed----------------------> failed
                                            |
                                            +--recoverable failure--> pending/failed with reason
```

- 套餐价格和权益来自服务端不可变目录；自定义充值只允许服务端范围内的整数金额。
- 订单创建保存服务端金额快照、权益快照和 provider 元数据。
- 发货先以订单条件更新认领 `processing`，再原子增加用户权益并 upsert 唯一流水。
- 重复查询、重复回调和进程重试通过订单唯一键与流水唯一键收敛为一次发货。
- 任何客户端 `success`、金额、用户 ID 或权益字段都不参与可信判断。

旺旺币兑换使用单条带余额下限条件的用户更新，避免“先读余额再扣减”的竞争窗口；成功后写唯一流水，流水失败进入可恢复记录而不是静默忽略。

## 文件与 STS 边界

简历记录只允许当前用户操作，文件对象键必须位于用户专属前缀。STS provider 返回短期、最小权限凭证；配置缺失时明确报错。前端从运行时配置读取 region/bucket，不硬编码真实 bucket。删除数据库记录与远端对象删除分开记录，避免伪造已删除远端文件。

## AI 上下文与 RAG

会话管理保留 system message、摘要和最近消息。达到阈值时异步生成摘要；失败时回退到固定窗口。定时任务清理过期内存会话。

RAG 采用接口隔离：检索器接收用户、职位和问题，返回带来源标识的有限片段。首个实现只索引当前用户已授权的面试知识或简历派生文本；无索引或 embedding 配置时返回空上下文。检索内容作为不可信上下文包裹，不能覆盖 system 指令。

## 可观测性

- AsyncLocalStorage 保存服务端生成或校验后的 TraceID，并在响应头回传。
- 日志序列化器递归脱敏 token、authorization、cookie、secret、password、私钥和简历正文等字段。
- HTTP 指标使用规范化路由模板，不以原始 URL、用户 ID、订单号或异常消息作标签。
- AI 指标记录模型、操作类型、耗时、结果和可得的 token 数；不记录 prompt/response 正文。
- 支付、兑换、登录等业务指标只记录低基数状态。

## 验证边界

自动化验证使用 fake provider、内存模型 mock 和静态配置检查，证明本地状态机与代码契约；真实 MongoDB、OSS、支付宝、微信商户、模型、Prometheus 抓取、Grafana 告警、Nginx TLS 和生产部署仍需要独立环境验收。
