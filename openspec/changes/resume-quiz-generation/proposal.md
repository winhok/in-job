# 简历智能押题生成

## 问题

用户需要基于已有简历快速获得结构化面试题目与分析，但现有能力缺少完整的文档解析、生成进度反馈、重复请求保护和结果留存流程。

## 范围

- 支持从受控 URL 下载并解析 PDF、DOCX 简历。
- 基于简历内容生成结构化押题题目与分析。
- 通过鉴权 SSE 接口返回阶段、进度、完成和错误事件。
- 对带 `requestId` 的请求提供幂等保护。
- 在生成前扣减用户额度，失败时尝试退款并记录消费状态。
- 持久化生成结果，供后续查询和复用。

## 非目标

- 不包含前端页面改造。
- 不包含生产部署、流量切换或发布声明。
- 不把本地测试和构建结果视为正式验收证据。

## 受影响契约

- 新增 `POST /interview/resume/quiz/stream` 鉴权接口，响应类型为 `text/event-stream`。
- 请求体包含简历标识、简历地址及可选的 `requestId` 等生成参数。
- SSE 事件包含 `progress`、`complete`、`error` 或 `timeout` 类型及对应载荷。
- 消费记录以用户和请求标识联合约束重复扣费。

## 风险

- 外部文件地址可能不可访问、超时或返回不支持的格式。
- AI 输出可能不符合结构化约束，需要解析和错误处理。
- 额度扣减成功但后续生成失败时，退款失败需要人工介入。
- 客户端断开连接后必须停止继续推送事件。

## 验收标准

- 合法 PDF 或 DOCX 简历能够进入结构化押题生成流程。
- 未鉴权请求不能调用 SSE 接口。
- 客户端能收到单调递增的进度事件以及明确的完成或错误事件。
- 相同用户和 `requestId` 不会重复扣费或重复生成成功结果。
- 生成失败会记录失败状态，并在已扣费时执行退款尝试。
- 生成成功会保存题目、分析及关联元数据。
